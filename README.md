<h2>Overview</h2>
<p>OleaGestion is a comprehensive developer tool tailored for managing olive oil logistics, client data, inventory, and transactions within a modular and maintainable architecture. It integrates core setup routines, a detailed database schema, and dynamic web interfaces to streamline operational workflows.</p>
<p><strong>Why OleaGestion?</strong></p>
<p>This project empowers developers to build scalable, efficient applications with features such as:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0">🧩 <strong>Modular Architecture:</strong> Facilitates seamless integration and maintainability through core setup routines and organized code structure.</li>
<li class="my-0">🛠️ <strong>Robust Database Schema:</strong> Supports complex business workflows involving clients, vehicles, fuel receipts, and payments.</li>
<li class="my-0">🎯 <strong>AJAX-Powered Forms:</strong> Enables real-time data management with secure, validated server interactions.</li>
<li class="my-0">🔍 <strong>Debugging Support:</strong> Source maps for CSS and JS assets simplify troubleshooting and customization.</li>
<li class="my-0">🧱 <strong>Object-Oriented Models:</strong> Ensures data consistency and clean code management across the system.</li>
</ul>

<h2>Getting Started</h2>
<h3>Prerequisites</h3>
<p>This project requires the following dependencies:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0"><strong>Programming Language:</strong> PHP</li>
<li class="my-0"><strong>Package Manager:</strong> Composer</li>
</ul>
<h3>Installation</h3>
<p>Build OleaGestion from the source and install dependencies:</p>
<ol>
<li class="my-0">
<p><strong>Clone the repository:</strong></p>
<pre><code class="language-sh">❯ git clone https://github.com/AYMANE777/OleaGestion
</code></pre>
</li>
<li class="my-0">
<p><strong>Navigate to the project directory:</strong></p>
<pre><code class="language-sh">❯ cd OleaGestion
</code></pre>
</li>
<li class="my-0">
<p><strong>Install the dependencies:</strong></p>
</li>
</ol>
<p><strong>Using <a href="https://www.php.net/">composer</a>:</strong></p>
<pre><code class="language-sh">❯ composer install
</code></pre>
<h3>Usage</h3>
<p>Run the project with:</p>
<p><strong>Using <a href="https://www.php.net/">composer</a>:</strong></p>
<pre><code class="language-sh">php {entrypoint}
</code></pre>
<h3>Testing</h3>
<p>Oleagestion uses the {<strong>test_framework</strong>} test framework. Run the test suite with:</p>
<p><strong>Using <a href="https://www.php.net/">composer</a>:</strong></p>
<pre><code class="language-sh">vendor/bin/phpunit
</code></pre>
